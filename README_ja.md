<h1 align="center">⌨️ Keyboard Utils Chrome Extension</h1>

<p align="center"><strong>どのページもホームポジションのまま、Vim 風に操作</strong></p>

Keyboard Utils は plain JavaScript で書いた Manifest V3 の Chrome 拡張機能である。ビルドは不要で、リポジトリのディレクトリがそのまま拡張機能になる。

## ✨ Features

- **Vim 風のスクロール** — `h` / `j` / `k` / `l` でスクロールし、数字で回数を指定でき、最上部や最下部へも移動できる。ページ全体ではなく内側のペインをスクロールさせる Web アプリでもスクロールできる
- **クリック用のヒント** — クリックできる要素すべてにラベルを付け、ラベルを打つとその要素をクリックする。大きく目立つ要素ほど押しやすい文字でできた短いラベルを付け、対象を枠で囲むので、ラベルがどの要素を指すかがわかる
- **バックグラウンドのタブで開く** — ヒントで選んだリンクを、今のページを離れずに新しいタブで開ける
- **入力欄へのフォーカス** — 入力欄にすぐフォーカスできる。複数見えていればヒントで選べる
- **履歴の移動** — キーボードで履歴を戻ったり進んだりできる
- **邪魔をしない** — 入力欄にフォーカスがある間はキーをそのままページに渡す。URL の正規表現でサイトごとに無効化できる
- **カスタマイズと同期** — キー、ヒント文字、スクロール量を変えられる。設定は Chrome プロファイルで同期され、要求する permission は `storage` だけ

## 🚀 Quick Start

**前提**：デスクトップ版の Chrome

1. このリポジトリを clone する

   ```bash
   git clone https://github.com/amaya382/chrome-keyboard-utils.git
   ```

2. `chrome://extensions/` を開く
3. 「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」を押し、clone したディレクトリを選ぶ

導入前から開いていたタブは再読み込みが要る。長めのページを開いて `j` を押し、下にスクロールすれば動いている。

更新するときは `git pull` してから、`chrome://extensions/` の拡張機能カードにある再読み込みボタンを押す。

## ⌨️ Keys

| キー | 動作 |
| --- | --- |
| `h` / `j` / `k` / `l` | 左 / 下 / 上 / 右にスクロール。前に数字を付けられる (例: `5j`) |
| `gg` / `G` | ページの最上部 / 最下部へ移動 |
| `i` | 入力欄にフォーカス。複数見えていればヒントを出す |
| `f` | クリックできる要素にヒントを出し、選んだ要素をクリック。`Shift` を押しながらラベルを打つとリンクをバックグラウンドの新しいタブで開く |
| `Backspace` / `Shift` + `Backspace` | 履歴を戻る / 進む。数字の前置に対応 (例: `3` に続けて `Backspace` で 3 ページ戻る) |
| `Esc` | 入力欄から抜ける。ヒントを閉じる |

`Esc` 以外のキーは設定で変えられる。

## ⚙️ Configuration

拡張機能の「詳細」から「拡張機能のオプション」を開く。

| 設定 | 既定値 | 説明 |
| --- | --- | --- |
| Keys | [Keys](#️-keys) を参照 | コマンドごとのキー列。Record を押すと実際に押したキーをそのまま記録し、`Esc` で終わる |
| Hint characters | `asdfgqwertzxcvb` | ヒントのラベルに使う文字。押しやすい順に並べる |
| Scroll step | `60` | `h` / `j` / `k` / `l` 1 回でスクロールするピクセル数 |
| Disabled URLs | (空) | 1 行に 1 つの正規表現。どれか 1 つでもページの URL に一致すると Keyboard Utils を無効にする |

特殊キーは `KeyboardEvent.key` の名前を山括弧で囲んで書く (例: `<Enter>`)。`Shift` 付きは名前の前に `S-` を付ける (例: `<S-Backspace>`)。

次の場合は保存できない。

- キーが空
- あるコマンドのキー列が別のコマンドのキー列の先頭と一致する (`g` と `gg`)
- ヒント文字が 2 種類未満
- 正規表現として解釈できない行がある

設定は `chrome.storage.sync` に保存され、同じ Chrome プロファイルにログインしたすべての端末に同期される。保存した変更は、開いているタブにも再読み込みなしで反映される。

## 🔒 Permissions

- `storage` — 設定の保存と同期
- すべてのサイトへのアクセス — 各ページでキー入力を処理する

## 🔧 Troubleshooting

### ページでキー操作ができない

Chrome は `chrome://` のページと Chrome Web Store では拡張機能を動かさない。それ以外のページなら、導入後にタブを再読み込みしたかと、Disabled URLs にそのページと一致する行がないかを確かめる。

### サイト自身のショートカットとぶつかる

YouTube などのサイトは同じキーを使う。そのサイトの正規表現を Disabled URLs に足す (例: `^https://www\.youtube\.com/`)。

### 埋め込みコンテンツをクリックした後にキー操作ができない

Keyboard Utils はトップレベルのフレームでだけ動く。フォーカスが iframe の中にあるときは、iframe の外をクリックしてページにフォーカスを戻す。

### ヒントが付かない要素がある

Shadow DOM の中の要素はヒントの対象にならない。

## 🧪 Development

編集したら `chrome://extensions/` の拡張機能カードにある再読み込みボタンを押し、確かめるページも再読み込みする。
